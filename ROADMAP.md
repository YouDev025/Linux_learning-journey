# Linux Learning Journey Roadmap

This roadmap provides a step-by-step path from beginner to advanced Linux skills for cybersecurity learners.

## Beginner Stage

1. `00-linux-fundamentals` — Learn what Linux is, common distributions, and the Linux command line.
2. `01-system-architecture` — Understand the kernel, boot process, and service initialization.
3. `02-filesystem-hierarchy` — Learn how Linux directories are structured and why each directory matters.
4. `03-file-operations-permissions` — Practice file commands and permission models.
5. `04-users-groups-management` — Manage user accounts, groups, and sudo privileges.

## Intermediate Stage

6. `05-process-management` — Control processes, foreground/background jobs, and signals.
7. `06-package-management` — Use APT and DNF/YUM to install, update, and audit packages.
8. `07-networking-fundamentals` — Configure networking, troubleshoot connectivity, and secure traffic.
9. `08-storage-disk-management` — Partition disks, configure filesystems, and use LVM.
10. `09-shell-bash-scripting` — Build scripts, automate tasks, and process text.

## Advanced Stage

11. `10-services-daemons` — Manage systemd services, analyze logs, and ensure availability.
12. `11-security-hardening` — Apply hardening controls, audit systems, and defend against threats.
13. `12-monitoring-performance` — Monitor host health, tune performance, and collect metrics.
14. `13-labs` — Complete real-world lab exercises to validate knowledge.
15. `14-projects` — Build portfolio-ready projects that demonstrate practical Linux expertise.

## Supporting Skills

- `15-cheat-sheets` — Keep concise references for commands, networking, and security.
- `16-interview-preparation` — Review common questions, hands-on tasks, and portfolio advice.
- `17-resources` — Use curated books, courses, and documentation to continue learning.

## Practical Learning Approach

- Read conceptual guides.
- Practice with labs and scripts.
- Build tools that solve real problems.
- Keep notes and commit project work to your portfolio.
