# Security Cheat Sheet

Essential security commands and hardening references.

- Account audit: `lastlog`, `passwd`, `chage`
- Authentication: `sshd_config`, `ssh-keygen`, `pam`
- File integrity: `aide`, `tripwire`
- Logs: `journalctl`, `ausearch`, `auditctl`
- Hardening: `selinuxenabled`, `apparmor_status`, `ufw status`
