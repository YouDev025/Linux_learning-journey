# Network Troubleshooting Lab

Objective: Diagnose and resolve a networking issue using Linux tools.

Tasks:
1. Use `ip addr` and `ip route` to inspect interface configuration.
2. Test connectivity with `ping` and `traceroute`.
3. Review DNS resolution with `dig` or `host`.
4. Identify issues and propose corrective actions.

Validation:
- Can reach the target host
- Correct route and DNS resolution are present
