# CLI Fundamentals Lab

Objective: Build confidence with basic Linux navigation and file operations.

Tasks:
1. Use `pwd`, `ls`, and `cd` to explore the filesystem.
2. Create a lab directory and create sample files with `touch`.
3. Copy, move, and delete files.
4. Use `find` to locate files by name.

Validation:
- `ls -al` shows expected files
- `find . -name "*.txt"`
