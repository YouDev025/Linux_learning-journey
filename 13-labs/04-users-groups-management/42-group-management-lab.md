42 Group Management Lab

## Exercise 1: Follow the Procedure
1. Open a terminal and review the lab topic.
2. Run the commands or steps described in the lesson.
3. Record the output and note any unexpected behavior.
4. Compare your results with the expected outcome.

### Expected Result
You should be able to explain the concept, run the command, and describe the result clearly.

## Exercise 2: Practice the Command
1. Re-run the main command from the lesson.
2. Try a variation of the command with a different input or option.
3. Observe how the output changes.

## Exercise 3: Check Your Understanding
1. Explain the purpose of the command or concept in your own words.
2. Identify one key detail you noticed during the exercise.
3. Write down one question you still have.

## Exercise 4: Troubleshoot and Reflect
1. If something failed, identify the likely cause.
2. Compare your result with the expected behavior.
3. Note one improvement you would make next time.

## Exercise 5: Validate Your Work
1. Confirm that the main task was completed.
2. Check that the output is reasonable and complete.
3. Summarize what you learned from this lab.
